# Pedigree symbol acceptance checklist

This checklist is an engineering aid based on the NSGC pedigree nomenclature resource (Bennett et al., 2022, doi:10.1002/jgc4.1621) and its 2025 correction (doi:10.1002/jgc4.2020). It is not a clinical conformance certificate, endorsement, or replacement for review of the source guidance. Results are limited to the examples explicitly exercised.

| Case | Expected representation | Current status |
| --- | --- | --- |
| Person | Square, circle or diamond as selected | Implemented; review symbol choice and gender context |
| Affected | Shading tied to a named condition | Primary condition plus up to three additional named conditions; broader condition models and independently reviewed legends remain incomplete |
| Deceased / proband | Diagonal slash / arrow | Implemented |
| Sex assigned at birth | Relevant AMAB or AFAB annotation, separate from selected symbol | Implemented for recorded male/female values when different from the selected symbol; other and unassigned cases need further work |
| Family history unavailable | Question mark above the person's symbol | Implemented |
| Stillbirth | SB annotation | Implemented |
| Ongoing pregnancy / loss / termination | P / triangle / slashed triangle | Implemented for selected outcomes; gestational age and full pregnancy scenarios need review |
| Twins | Shared branch; monozygotic pair connected | Implemented for two entries with matching group ID and genetic parent set; complex multiples and placement need work |
| Consanguinity | Double partner line | Implemented when recorded |
| Adoption | Brackets and non-genetic parent link | Partial: a dotted line is skipped if the adoptive parent is not in an earlier inferred generation; line routing may cross other elements |
| Partner separation | Relationship history visible | Text only; visual relationship-break symbols are incomplete |
| Donor conception and gestational carrier | Distinct, accurately linked people and relationships | Partial: explicit donor roles and gestational person are displayed as labeled links in eligible layouts without inferring a couple; complex scenarios, placement and NSGC conformance require independent review |
| Multiple affected conditions / carrier findings | Distinct patterned subdivisions and an explanatory legend | Partial: up to three additional affected or reported-carrier conditions with a per-person key; further conditions and independent clinical verification remain outstanding |
| Multiple individuals and unknown number | Count or n inside symbol, without implying one individual | Not implemented |
| Birth order, intersecting lines and complex relationships | Accurate, legible diagram | Not guaranteed; manual review is required |

Before clinical deployment, representative cases must be independently reviewed against the complete resource and correction, verified through editing, encrypted backup, reopening and PDF export, and accompanied by accessibility, privacy, security and institutional review.
