Your publishing routine

  1. Open Blog articles and create an article.
  2. Add a title, date, author, topic, summary, and optional cover image.
  3. Write and review the formatted article in the visual editor. This previews content formatting, not the exact website layout.
  4. Leave Publish on the website off while drafting. Turn it on and save when ready.
  5. GitHub builds the site. After deployment, find your article under Blog.
Drafts are not confidential. This GitHub repository is public. Saved drafts and uploaded images can be viewed in the repository even when excluded from the blog. Do not store unpublished sensitive research here.

First-time connection

After these website files are deployed, sign in to Pages CMS and approve its GitHub App for only this website repository. Review the requested permissions before approving. The editor configuration is already included; no passwords or access tokens belong in website files.

Publishing requires repository write permission. Saving commits the article to GitHub; a failed deployment leaves the previous website online. Dates label articles; they do not schedule publication.
