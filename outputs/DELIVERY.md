# terminalBio rebuild delivery

The completed website implementation is in the parent project directory.

Key files:

- `../index.html`
- `../src/style.css`
- `../src/main.js`
- `../package.json`

It is a Vite project. Install Node.js 20+ and run `npm install`, followed by `npm run dev` for local development or `npm run build` for a production bundle.

GitHub Pages deployment is configured in `../.github/workflows/deploy-pages.yml`. After uploading the project to `iamhamzaabdullah/terminalbio.github.io`, select GitHub Actions under the repository's Settings → Pages. Pushing to `main` then deploys automatically.
